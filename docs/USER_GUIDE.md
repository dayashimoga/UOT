# User Guide — Universal Offline Transfer (UOT)

> **Step-by-step instructions for file transfers, pairing, and streaming.** Updated: 2026-08-09 (Sprint 11 Audit).

---

## 1. Quick Start Guide

### Sending Files
1. Open UOT on both devices (must be on same Wi-Fi/LAN or connected via hotspot/BLE).
2. On the **Nearby** screen, select the target device from the discovered list.
3. Tap **Select Files** (or drag & drop on desktop).
4. Enter the 6-digit PIN if prompted (or auto-connect if device is trusted).
5. File transfer begins immediately with progress indicator, speed, and ETA.

### Receiving Files
1. Open UOT and navigate to the **Receive** tab.
2. Ensure Visibility is set to **Visible to Everyone** or **Visible to Trusted Devices**.
3. When an incoming transfer offer arrives, review the file list and tap **Accept**.
